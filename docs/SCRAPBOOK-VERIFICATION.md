# 手账首页与持续动效

日期：2026-10-15。根据用户确认的改进方案，继续优化暖色四屏首页。

## 变化

- 首屏完整名称、侧边纸质头像、手绘连线和三个插画主题书签；背景左侧阅读区更浅，右侧保留插画。
- 三个主题采用笔记页、唱片与相片、可翻开的便签构图。插画均保留素材标记，不冒充项目或现场照片。
- 标题字母持续微幅起伏，太阳与装饰唱片慢转；没有自动音频。工具栏提供暂停和恢复循环动效。
- 系统减少动态效果时取消动画，按钮提示系统偏好；标签页隐藏时暂停装饰动画。暂停仅针对循环装饰，导航和主动操作仍有效。
- `HomeScene.vue` 封装主题构图，`useAmbientMotion.js` 管理动态状态，`scrapbook.css` 保存本轮样式。书签文案与笔记标签仍在 `src/data/home.js`，便签示例复用 `littleThings.js`。

## 实际验证

- `npm test`：3 项滚轮手势逻辑测试通过。`npm run build`：成功。
- 暂停后全部标题字母与太阳的计算样式为 `animation-play-state: paused`，恢复后继续；唱片循环为运行状态。
- 原生滚轮从封面仅进入 World 一屏；四屏目录仍然有效。
- 书签能切到对应主题；主题的图片入口或文字入口分别到达 World、Music、Little 详情，详情页正常滚动，品牌链接能回首屏。
- 纸条点击显示示例文字、更新按下状态，再次点击可收起。示例内容明确标记。
- 320×568、390×844、768×1024、1440×900 下分别检查四屏，共 16 组，无页面或屏内横向溢出，底部控件可见，已加载图片无失败。矮屏主题内容允许内部滚动；320×568 封面缩减间距后可完整容纳。
- 另外检查 1280×720、1024×768 的四屏，共 8 组，内容完整容纳且无屏内横向溢出。
- 浏览器控制台未出现 warning 或 error。
- 桌面及手机封面截图在 `docs/previews/scrapbook-home-desktop.jpg`、`scrapbook-home-mobile.jpg`，另外保存 Music 和 Little 构图预览。

## 未覆盖

- 手机使用视口模拟，未在真实手机上操作触摸手势；未进行跨浏览器及屏幕阅读器测试。
- 系统减少动态与后台暂停已从代码检查，但没有实际更改操作系统偏好或切换标签验证。暂停按钮已实际操作。
- 原始素材仍较大，发布前需要准备网页尺寸版本。本轮不部署网站。
