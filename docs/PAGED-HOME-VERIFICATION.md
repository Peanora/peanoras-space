## 2026-10-16 五项优化与实际验证

- 歌曲封面显式设置响应式高度与正方形比例；390px 视口实际尺寸由 100×600 改为 100×100，歌曲条目高度由约 802px 降为 302px。768px 为 165×165，1440px 为 230×230。
- 文楷常用包 130,872 字节，覆盖 645 个当前字符；其余字符由 132 个互不重叠的小包按需提供，最大 92,628 字节。CSS 范围合并后覆盖原字库全部 25,694 个字符，没有重叠；完整的 5.3 MB WOFF2 未进入生产产物。浏览器临时加入“麒麟”后仅请求对应的 89,724 字节分包，不需要重新生成字体。原字体与许可仍保留。
- 未完成的项目、经历、现场回忆、相册设为隐藏，正式页面及页内导航不再出现这些占位模块；编辑器实际可找到原条目和“显示模块”按钮，没有删除原始内容。首页主题介绍同步反映当前内容。
- 首页三个书签标明“翻到主题”，箭头改为向下；顶部导航明确直达详情、底部目录翻页。实际验证书签翻到 World、键盘与原生滚轮翻到后续主题、顶部导航进入 World，四屏结构保留。
- 首页、About 与页脚的 GitHub 统一为 Peanora。SVG/PNG/ICO/Apple 图标、现有头像制作的 1200×630 分享封面可用；四个静态 HTML 分别包含标题、描述、canonical、Open Graph 与 Twitter 卡片，404 静态 HTML 不设 canonical 并标记 noindex。站内导航同步更新页面 metadata。

- Chromium 在 320×568、390×844、768×1024、1440×900 下检查四页，共 16 组：无横向溢出、已加载图片无失败、无旧 GitHub 链接、无完整字体请求，歌曲封面比例正确；四页当前字体请求合计约 219 KB。生产常规浏览控制台无错误/警告。
