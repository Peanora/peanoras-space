# 官方音乐播放器 · 2026-10-15

## 来源与实现

- 用户提供《它像一颗》网易云分享链接，歌曲 ID `1982799628`。公开歌曲 HTML 确认曲名、艺术家 Hanser，并有“生成外链播放器”入口。
- 官方生成页 `https://music.163.com/outchain/2/1982799628/` 返回 200，提供 iframe 模板；实际嵌入 `https://music.163.com/outchain/player?type=2&id=1982799628&auto=0&height=66`。
- `src/data/songs.js` 为歌曲配置；没有复制音频或官方封面，未提供的感想保持空值，封面继续明确标记占位。
- `MusicPlayer.vue` 放在持续存在的 SiteHeader 中。打开面板本身不加载第三方，点击加载或歌曲列表入口才创建 iframe。收起使用 v-show；路由内容不包含播放器，因此站内切页不卸载。停止卸载 iframe，重新加载重新创建。
- 不读取或转换本地 NCM，不代理音频，不尝试绕过平台限制。面板始终提供官方歌曲链接；慢加载提示与手动重试可用。iframe load 事件只更新提示，不被当成播放成功或音频状态。
- 小面板非模态，不锁定阅读；菜单与播放器面板互斥，Escape 收起并恢复焦点，首页键盘翻页忽略音乐面板中的按键。
- 为新增中文重建约 95KB 的文楷核心字体，完整回退文件保持原版本，避免新增曲名触发整个字体下载。

## 实际验证

- 12 项 `npm test` 通过，含官方地址 auto=0、首次不加载、共享状态、同曲重开不重载、收起保留、停止卸载、手动重试和无效曲目拒绝。
- `VITE_BASE_PATH=/peanoras-space/` 下生产构建通过。
- 本地生产预览实际浏览器：首次 iframe 数为 0；打开面板仍为 0；点击加载后为 1。
- 360×640 下，头部按钮、面板、官方控件均可见，页面无水平溢出。截图 `previews/official-music-player-mobile.png`。
- 嵌入内实际显示《它像一颗 - Hanser》与封面；点击官方播放按钮后暂停控件显示，剩余时间持续变化（依次观察到 `-04:08`、`-03:19`、`-03:00`）。这是播放进度与控件的实际观察，不等于人工听音或手机实机验收。
- 收起后 iframe 保留；从首页经菜单进入 `#/music`、再次展开后进度未重置。官方暂停按钮实际切换为播放按钮。
- 本站“停止播放”后 iframe 数为 0；Escape 收起并将焦点返回“听歌”；音乐页“打开播放器”可重新创建同一个面板。
- 官方脚本记录了跨域读取顶层窗口失败的 SecurityError（网易云脚本域），本地观察期间仍可播放和暂停。没有放宽跨域安全策略，不将控制台全部标为无错误。

## 限制

- 直接用自动化浏览器打开歌曲页与外链页曾超时；通过本站 iframe 的实际加载与交互完成上述验证。
- 无真实手机、不同浏览器、不同账号/地区/运营商测试；平台未来可能改变可用性。
- 第三方 iframe 内部 UI、键盘支持、音量/播放策略由官方决定，本站不承诺完全自定义或所有环境可用。
