## 尚未验证与需要本人验收

- 真实手机和平板的触摸、系统浏览器与屏幕旋转；浏览器视口模拟不等同于实机测试。
- Safari、Firefox 等其他浏览器及屏幕阅读器。
- 系统减少动态效果偏好的实际切换；代码已提供 CSS 和滚动出现逻辑的对应支持。
- 浏览器禁止存储、存储配额耗尽与损坏记录的实际环境；代码提供异常处理，但未修改浏览器设置进行模拟。
- 正式外链是否有效：目前 GitHub、项目演示与歌曲官方地址尚未提供，因此没有虚构链接。
- 正式图片、中文长文、较多项目与回忆加入后的排版和加载性能。
- 真实 GitHub Pages 托管与 Actions 部署；第一阶段没有远程仓库或部署操作。
