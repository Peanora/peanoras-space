# 暖色插画视觉首版

此文件保留 2026-10-14 首版记录；首页布局已由 2026-10-15 四屏方案替代。当前约定见 [产品需求](PRODUCT_REQUIREMENTS.md)，最新验证见 [四屏首页验证](PAGED-HOME-VERIFICATION.md)。下文的待推送状态仅描述当时情况。

2026-10-14：根据本人提供的头像与十张插画壁纸，将默认视觉调整为奶油白、暖杏色和深棕文字。当前以首页视觉为主要调整对象，其他页面同步基础配色与阅读底色。

## 素材与布局

- 头像使用第一张图片，以 CSS 圆形裁切展示，原图不改动。
- 默认背景为秋日树林，十张壁纸均可手动选择，不自动轮播。
- 壁纸透明度为 30%，叠加暖白遮罩，最终图像分量约为 14%。正文使用深棕色，长内容区另加浅色阅读底。
- 首页姓名字号缩小，加入头像与两个同等重要的主题入口。
- 首页入口图为春日庭院和花海主题插画，标记为插画壁纸，不代表项目截图或现场摄影。
- 壁纸选择保存在当前浏览器的 `peanora:wallpaper:v1`，读取失败时使用默认背景。
- 全部 JPG 为原图复制，原文件未修改。目前尚未生成小尺寸的网页图像版本；正式上线前仍需处理大图加载体积。

## 实际验证

- 四个页面在 360、390、768、1440px 下共 16 个组合无横向溢出，已加载图片未发现失败。
- 实际操作了壁纸切换、刷新恢复和 Escape 关闭，焦点返回选择按钮。
- 壁纸最暗像素按全黑计算，考虑两层遮罩后，正文色对比度约 7.36:1，次级文字约 4.69:1，链接点缀色至少约 4.53:1。计算是背景模型下的下界，仍需真人检查实际视觉舒适度。
- 当前内置浏览器未发现网站 warning 或 error 日志。
- 真实触摸设备与其他浏览器仍需实机验收。
- 最终构建检查通过；手机菜单、壁纸面板边界和浅色灯箱亦已操作检查。
