# 欢迎语、打字机签名与中文字体

日期：2026-10-15。用户明确要求头像再右移、左侧加入欢迎语与个性签名，并避免系统字体；这项要求替代早期首页不放欢迎语或签名的约定。

## 内容与实现

- 欢迎语：“欢迎来到我的小空间”。签名：“好好睡觉，好好吃饭，好好上班，好好上学~”。两者在 `src/data/site.js` 的 `welcome`、`signatures` 修改；签名可继续增加数组条目。
- `SignatureTypewriter.vue`：按字素逐字打出（125ms）、完整停留（2200ms）、逐字删除（70ms）、留白（650ms）后切下一句；单句也循环。字母/汉字出现时轻微上移和淡入。
- `typewriter.js` 独立管理文本帧，Vue 组件管理定时器；隐藏页面、暂停动态及组件卸载时停止计时。恢复继续；系统减少动态时显示完整第一句。
- 隐藏占位文字按所有签名中最高的一条预留空间，防止打字/删除引起布局跳动；视觉字符从无障碍树隐藏，提供完整的静态签名文本，不逐字播报。
- 头像桌面向右对齐并为旋转和太阳保留边距。移动端欢迎语和签名移至标题/头像下方，使用完整行宽；矮屏保留书签入口并省略重复的翻开按钮。
- 中文改为自托管霞鹜文楷轻便版，英文保留 Kalam 与 Nunito。字体来源、版本和 SHA-256 在 `src/assets/fonts/LXGW-SOURCE.md`；OFL 和网页转换附加许可保留在源码及构建产物。
- 当前中文小字库约 94KB；新增字自动使用完整网页字库。更新签名无需生成新字体，也不依赖浏览器访问外部字体服务。

## 实际验证

- `npm test`：5 项通过，其中新增打字机顺序、停留/删除/切换、空列表、单句循环和组合字符不拆分的测试。
- `npm run build` 成功，两个 WOFF2 及许可被复制到构建产物。
- 字体文件解析成功；欢迎语与完整签名的字形无缺失；本地字体样式已出现在页面，浏览器没有字体解码报错。
- 实际观察到签名的打字、完整停留和删除阶段；暂停后跨多次观察文字保持完整，恢复后逐字删除。
- 从完整停留到删除，入口按钮的顶部位置均为 479.375px（1280×800）；没有因删除导致位置跳动。
- 首页四屏在 320×568、390×844、768×1024、1440×900 下共 16 组无横向溢出，控制栏可见。320×568 封面可一屏容纳，主题详情较长时允许屏内阅读。
- 三个详情页在上述四种尺寸下共 12 组无横向溢出，已加载图片没有失败。浏览器控制台没有 warning 或 error。
- 桌面和手机截图为 `docs/previews/welcome-home-desktop.jpg`、`welcome-home-mobile.jpg`。

系统减少动态、后台自动暂停已检查实现，未实际切换操作系统偏好验证；未在真实触摸硬件、跨浏览器及屏幕阅读器上实测。完整新文字回退字库尚未通过新增生僻字的浏览器场景验证，字体转换与 CSS 回退声明已检查。
