## 播放与更新

- 首访不下载音频、不自动播放；选歌后点击播放才设置 audio.src。保持单一原生播放器，支持暂停、手动切歌、进度、音量与主动单曲循环，默认不自动连播。
- 收起面板或站内换页保留音频元素与位置。未配置公开音源的歌曲仍可使用官方播放器，官方收听链接、停止与重试继续保留。
- 数据流：content.json 歌曲 ID → audio.json 公开文件映射 → 同源 audio 元素 → 真实媒体事件更新进度/时长。开发环境可用本机清单覆盖，正式构建只使用公开清单。
- 常规 npm run build 将公开文件复制到 dist/audio/hanser/，现有 Actions 发布 dist；不需要新服务、密钥、代理或浏览器第三方登录。
- 新增其他音源时应另行确认发布范围，不把整份本机目录自动同步到公开目录；修改已公开文件时同步其字节数和 SHA256，并验证可播放。
